Introduccion a JavaCash API

Bienvenido a la documentacion de la API de JavaCash. Esta guia te ayudara a integrar pagos entrantes (PayIn) y salientes (PayOut) en tu aplicacion de forma segura y eficiente.

Que es JavaCash API?

JavaCash API es una interfaz REST que te permite procesar transacciones financieras en Latinoamérica. Con nuestra API puedes:

  • Recibir pagos (PayIn): Genera enlaces de pago seguros para tus clientes
  • Enviar fondos (PayOut): Realiza transferencias a cuentas bancarias o billeteras digitales
  • Consultar estados: Verifica el estado de cualquier transaccion en tiempo real
  • Gestionar webhooks: Recibe notificaciones automaticas de cambios de estado

Caracteristicas Principales

Seguridad

Autenticacion mediante API Key con encriptacion SSL/TLS en todas las comunicaciones.

Velocidad

Procesamiento en tiempo real con respuestas en milisegundos.

Confiabilidad

99.9% de uptime con infraestructura redundante y monitoreo 24/7.

Multi-tenant

Soporte nativo para multiples paises y monedas con aislamiento de datos.

Parámetros por País

El contrato de la API es el mismo en todos los países. Lo que cambia es el valor que debes enviar en currency y el documento de identidad que espera userIdentificationNumber.

País currency Documento Ejemplo
{{ country.flag }} {{ country.name }} {{ country.currency }} {{ country.identification.label }} {{ country.identification.example }}

Tipos de Cuenta (PayOut)

El campo userTypeAccount siempre acepta los mismos dos valores, savings y checking. El nombre comercial que usa cada país es distinto:

País savings checking
{{ country.flag }} {{ country.name }} {{ country.accountTypes.savings }} {{ country.accountTypes.checking }}
